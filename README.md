🛒 MERN E-Commerce Website

A Full-Stack E-Commerce Web Application built using the MERN Stack (MongoDB, Express.js, React.js, and Node.js).

📌 Project Overview

MERN E-Commerce is an online shopping application designed to provide users with a smooth shopping experience. It includes product browsing, user authentication, cart management, checkout, and administrative product management.

🚀 Features

- User Registration and Login
- Product Listing and Details
- Shopping Cart Management
- Checkout and Address Management
- Order Management
- Admin Dashboard
- Product Management

Only retain features that are implemented and working in the project.

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/himanshu234-ess/MERN-E-COMMERCE.git

2. Navigate to the project

cd MERN-E-COMMERCE

3. Install backend dependencies

npm install

4. Install frontend dependencies

cd frontend
npm install

5. Configure environment variables

Create a ".env" file using the required variables from your backend configuration.

Never upload actual credentials or API secrets.

6. Run the application

Use the start scripts defined in the backend and frontend "package.json" files.
